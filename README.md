# cashback-vendas-js

Exercício prático de manipulação de dados em JavaScript, usando os principais métodos de array (.filter(), .map(), .forEach()) para simular um sistema simples de cashback em vendas.

O que o script faz
Filtra os clientes que pagaram e compraram acima de R$ 200
Calcula o cashback de 10% sobre o valor de cada venda válida
Exibe no console uma mensagem formatada para cada cliente
